# Windows文件操作技能

## 基本命令
- `mkdir <目录名>` - 创建新目录
- `rmdir <目录名>` - 删除空目录
- `del <文件名>` - 删除文件
- `ren <旧名> <新名>` - 重命名文件/目录
- `copy <源文件> <目标路径>` - 复制文件
- `move <源文件> <目标路径>` - 移动文件

## 常见问题解决
1. **权限问题**：以管理员身份运行命令提示符
2. **文件被占用**：关闭使用该文件的程序
3. **路径包含空格**：使用引号包围路径，如 `"Program Files"`

## 安全注意事项
- 删除文件前确认文件名正确
- 重要文件后备份再操作
- 避免在系统目录随意删除文件
