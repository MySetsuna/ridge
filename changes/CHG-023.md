# Eliminate rounded box cell-edge gaps

Rounded corner rasters and straight box rasters can have different native
advances after font fallback. Pixel-snapped cell allocation then leaves one
transparent device pixel between the corner's declared connector and the next
cell even though their axes and coverage profiles match.

Keep the main selected-font bitmap at one source texel per device pixel. When a
box glyph's native quad does not reach a snapped cell side, append only a side
strip sampled from that outermost source texel. Do not rescale the curve or the
complete glyph.

Acceptance:

- A narrower rounded-corner bitmap reaches the exact snapped cell edge without
  changing its main quad size or UV density.
- The side strip reuses the outermost native texel column and preserves nearest
  WebGPU sampling.
- Box glyphs already covering the allocation emit no redundant strip.
- Ordinary text and color emoji geometry remain unchanged.
- Ridge-term WebGPU tests, WASM build, and STC gates pass.
