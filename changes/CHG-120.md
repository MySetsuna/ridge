# 补齐 Remote 连接前更新入口并共享编辑保护提示

Remote 的 SW 在前台等待应用更新，提示却仅在连接成功的 MainApp 出现。登录、连接失败或模块加载错误页缺少前台应用入口。抽出共享提示，在连接前与已连接页面互斥呈现，复用既有稍后、保存、丢弃、并发和失败重试门禁。连接前页面按提示实测高度让位，保留安全区、滚动与认证布局。用生成的真实 Workbox SW、真实 Chromium 和隔离 HTTP 静态宿主验证等待版本在 LAN 认证页及 Cloud 登录失败页可见，稍后保持等待，点击后真实激活并重载。Cloud 认证后端仅使用只读 401 fixture，测试不作为公网连接或真机结论。全量工程门禁照常。
