# Move kernel PTY writes off the async HTTP handler

The kernel HTTP PTY-write endpoint shall not execute the blocking PTY writer on
an async runtime worker. It shall preserve controller validation and response
semantics while moving the blocking write operation to a blocking task, so
health, topology, output polling, and subsequent PTY requests remain
responsive.

Acceptance:

- A real authenticated `write_to_pty` request receives a result promptly.
- The shell executes a unique marker and the existing browser E2E observes
  shell echo and desktop `manager.feed` output.
- PTY controller and unknown-terminal errors remain fail-closed.
- Focused kernel tests, `stc verify`, and the full project gate results are
  reported.
