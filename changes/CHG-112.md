# 停止 Remote 与外部窗格调用本机进程轮询

公网 Remote 每秒调用 native-only get_pane_foreground_process，持续触发 1001；RidgePane 误以 isTauri 识别原生，但浏览器兼容层也返回 true。依据真实编译目标与外部 pane 绑定阻止本机轮询，不扩大权限、不修改后端拒绝契约；以构建、现有回归及公网请求计数验收。
