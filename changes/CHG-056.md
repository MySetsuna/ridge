# CHG-056 — M3 Default Agent Workflow

## §1 Scope

1. `acp_open_session` accepts `ProviderSpec` (kind/model) + `effort: Option<String>` from frontend
2. New Tauri commands for Commutation:
   - `commutation_open(plan, staff_specs)` — Lead + N Staff
   - `commutation_event_subscribe()` — broadcast subscription
   - `commutation_snapshot()` — state dump
   - `commutation_prompt_lead(text)` — Lead prompt
3. `packages/ridge-acp/src/provider.rs` — add `Effort` enum + `ModelSpec.effort` field
4. Session persistence:
   - `acp_session_save(path)` — write `AgentSessionSnapshot` + config to JSON
   - `acp_session_load(path)` — restore from JSON, spawn fresh transport

## §2 NOT in scope

- src-tauri runtime/PTY/Remote layer (frozen L2-REMOTE-MOBILE-SEMANTIC-V2)
- Bridge holds NO session/message/tool/approval business state (AgentSession single source of truth)
- Provider live wiring (Anthropic/OpenAI) — still NEXT_SLICE; ProviderKind enum already exists
- Removing legacy `read_agent_recent_replies` / `resume_agent_session` — callers verified but kept for backward compat

## §3 Single source of truth

```
Frontend (AgentChatPanel.svelte)
  ↓ invoke("acp_open_session", { provider: { kind, model }, effort })
Tauri command
  ↓ AgentSession::connect(transport, child, AgentSessionConfig{ provider, client_name, client_version })
AgentSession
  ↓ prompt_loop
AcpTransport
  ↓ stdio JSON-RPC
Provider binary (opencode-acp / mock_acp_agent)
```

Commutation:
```
Frontend
  ↓ invoke("commutation_open", { plan, staff_specs })
Commutation::new(plan, staff_specs)
  ↓ spawn Lead AgentSession + N Staff AgentSessions
Commutation::events() broadcast
  ↓ frontend invoke("commutation_event_subscribe") / Tauri event forwarder
```
