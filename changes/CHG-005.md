# Mobile Cloud RPC 接回統一內核分派

Cloud Host 仍接收 Remote 內核定義的平鋪 RPC 參數。桌面 WebView 不再按 RPC
方法直呼各 Tauri command，而經單一 `dispatch_remote_invoke(method, args)` shell
端口，復用 LAN 的 remote allowlist、JSON-RPC 錯誤與 `ridge_core::dispatch`。
`rdg` 可直接提供自身內核 context；協議不依賴 Tauri command 參數形狀。

## Acceptance

- 未限定 workspace 的 Cloud Host RPC 經 `dispatch_remote_invoke(method, args)`。
- workspace-scoped Cloud Host 經授權規劃後亦走同一端口。
- `resize_pane` 以平鋪參數進入既有 `CORE_MIGRATED_METHODS` 分派，不包 Tauri
  專用 `{ request }`。
- Remote allowlist 與結構化 JSON-RPC 錯誤語義不變。
- 移動端視口連入真實 Cloud tenant，初始 Host grid claim 成功，頁面不再出現
  `command resize_pane missing required key request`。
