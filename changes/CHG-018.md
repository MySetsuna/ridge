# Preserve Host color emoji in terminal font fallback

Host font discovery must retain a color-emoji face even when the configured CSS
fallback stack exceeds the bounded font payload. The WASM rasterizer must use
that Host face directly, keep Swash's premultiplied color pixels, and never
require a font install on the Remote or Cloud controller.

Box-drawing glyphs remain font-rasterized. Their existing connector pixels are
extended to the logical cell sides named by the Unicode glyph so adjacent cells
meet without replacing curves or antialiasing with hand-drawn geometry.
Monochrome text keeps native nearest sampling; color emoji and box drawing use
linear atlas sampling. TUI mode obeys DECTCEM but presents an enabled terminal
cursor continuously instead of suppressing it or scheduling blink frames.

Acceptance:

- A CSS stack longer than the Host face limit still resolves the installed
  color-emoji face; payload count and byte authorization bounds remain enforced.
- The production cosmic-text/Swash path rasterizes a real Host color emoji with
  non-gray premultiplied RGBA pixels.
- Horizontal, vertical, tee, and rounded-corner fixtures reach only their
  declared cell sides by copying source coverage; curve pixels remain unchanged.
- Shader validation covers separate nearest and linear atlas samplers. Only
  color emoji and box-drawing instances select linear sampling.
- Fullscreen and inline TUI fixtures show a DECTCEM-enabled cursor steadily,
  hide it when DECTCEM is disabled, and schedule no TUI blink wakeup.
- The terminal remains WebGPU/WebGL2 through wgpu; no Canvas2D presentation path
  or controller-side font installation is introduced.
