# 修复 Remote TUI 刷新、桌面菜单模式与手机游标跟随

Remote 刷新先按当前屏幕重申终端尺寸、清空旧帧，再请求当前 pane 的完整规范屏幕；
首次由 Shell 切入已运行 TUI 后，可凭刷新恢复完整当前画面。

桌面右键菜单若由活跃 inline TUI 打开，则建立有界交互租约；执行不替换终端的
菜单动作后续租并恢复焦点，避免菜单期间启发式衰减令输入误入 Shell 模式。

手机隐藏 IME 输入框不再绘制固定原生 caret；唯一可见游标归终端渲染器，
随 TUI 实际输入行移动并按终端状态闪烁。

## Acceptance

- 刷新在尺寸确认后丢弃旧队列并请求当前 pane 完整重同步。
- 首次切换至既有 TUI 后，刷新可恢复完整当前屏幕。
- TUI 菜单动作后保持 inline-TUI 输入路由；普通 Shell 菜单不获租约。
- 手机 IME sink 不绘制 caret；渲染器游标保持聚焦、跟行及闪烁。
- 既有测试、构建、检查及 SpecTree 验证通过。
