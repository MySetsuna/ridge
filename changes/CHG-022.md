# Align complete rounded box glyphs to straight axes

Replacing only a rounded corner's outermost row or column makes its cell edge
match a straight glyph but leaves the interior tangent on the font's original
axis. The result is a visible step inside all four corner cells; bottom corners
in the reported 19px frame differ from the adjacent horizontal line by four
device pixels.

Determine the rounded glyph's horizontal arm axis from its native selected-font
raster, translate the complete curve to the selected-font `─` axis, then fill
only the vacated declared vertical arm with the selected-font `│` profile.
Canonicalize the straight arm run up to the curve tangent, not merely its outer
edge. No procedural curve, outline reconstruction, or coverage thresholding.

Acceptance:

- Real 19px Regular and Bold Consolas `╭╮╰╯` interior horizontal tangents align
  with their corresponding real `─` profile after normalization.
- Each normalized corner joins real `─` and `│` with identical premultiplied
  edge coverage.
- Synthetic fixtures prove the complete native curve translates rigidly while
  vacated vertical-arm pixels are filled from the reference profile.
- Rounded-corner quads retain 1:1 source texel density and remain clipped to the
  physical cell without shadows, gaps, or duplicated arms.
- Ridge-term WebGPU tests, WASM build, and STC gates pass.
