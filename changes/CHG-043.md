# Fix PTY drain callback promise contract

## Semantic delta

PTY 输入 drain 的代入 callback 在 lane 已被替换时仍须返回已完成的 Promise，保持
`enqueuePtyWrite` 的异步接口契约，同时不执行旧 lane 的写入。

## Acceptance tests

1. `svelte-check`、`pnpm lint` 与 `pnpm typecheck` 不再因该 callback 的返回类型失败。
2. lane 失配时不写入旧 PTY；lane 有效时仍等待并传播当前写入 Promise。
3. 现有 PTY 队列测试全部通过。
