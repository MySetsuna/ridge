# 消除 Remote Service Worker 全量预热与鉴权缓存干扰

公网验收发现浏览器请求停滞，而独立网络探针正常；现有激活钩子全量并发预热 JS，缺少带宽与功能需求约束。删除可被按需缓存替代的全量预热，实时 API 和发布指纹绕过 SW；先保留原样例证明激活产生无需求下载，再验证不再预热及离线静态命中。安装提权与正式主机验收另行推进，本轮不改鉴权边界或终端协议。
