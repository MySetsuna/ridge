# Fix Remote terminal links, wallpaper, and LAN discovery

Remote terminal links expose only safe HTTP(S) URLs and origin-proven files
inside pane CWD/workspace scope. Matching boundaries shrink to the real token;
filesystem validation stays lazy, deduplicated, timeout-bounded, and cached.

WebGPU link underlines render at one CSS pixel without seams. Wallpaper remains
fixed to the viewport during terminal scrolling and stays visible beneath TUI
default cells; explicit TUI cell backgrounds remain opaque.

LAN discovery advertises every usable IPv4 on the RFC 6762 multicast address,
with resolvable A/SRV records per interface and a physical-LAN-first default.

## Acceptance

- Only valid credential-free `http://` and `https://` links open as webpages.
- A path underlines/opens only after its captured origin proves an existing,
  non-directory file inside CWD/workspace scope; negative probes are cached.
- OSC-8 unsupported schemes receive neither underline nor click affordance.
- Link underlines are one CSS pixel and continuous at fractional DPR.
- Wallpaper does not move with terminal scroll and is not reset to black by
  default-background TUI cells; explicit colored cells remain intact.
- Ethernet, Wi-Fi, VPN, and overlay IPv4 interfaces each emit a bounded mDNS
  announcement containing a matching A record and the live Remote port.
