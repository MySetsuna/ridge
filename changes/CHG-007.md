# Tighten monochrome glyph edge coverage

The first grayscale coverage remap leaves too many partially covered edge
pixels at the default DPR, so system-font terminal text remains visibly softer
than native terminal text.

## Acceptance

- Monochrome glyph coverage uses a tighter centred transfer curve while
  retaining antialiasing at the edge.
- The native CJK, symbol, and emoji fixture remains complete at DPR 1 and 1.25.
- At DPR 1, the first two monochrome fixture rows contain at least 70% solid
  pixels and no more than 30% transition pixels.
- Color emoji alpha, system CSS fallback selection, glyph geometry, terminal
  cell widths, and the WebGPU/WebGL2 presentation backends remain unchanged.
