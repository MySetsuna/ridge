# Parse kernel HTTP responses by Content-Length for host PTY I/O

## Semantic delta

The kernel HTTP adapter may keep a persistent connection after returning a
JSON response. The synchronous kernel client shall parse a complete response
from `Content-Length` instead of waiting for TCP EOF, so host-side PTY input
and other domain requests complete within the bounded request timeout.

## Acceptance tests

1. A kernel response with `Content-Length` and keep-alive completes through
   `request_json` without waiting for connection close.
2. Host PTY input returns an invoke result and preserves the full marker after
   real browser keyboard input.
3. Existing kernel client auth, status, and bounded timeout behavior remain
   unchanged.
