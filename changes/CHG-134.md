# 文件树读取失败与原地重试

落实 L3-RUNTIME-WORKSPACE-CONTINUITY 已有错误传播要求。首层目录读取失败须呈现列内错误、实际请求目录及显式重试；越界、目录不存在与其他读取失败可区分。失败不能生成成功空树，也不能把已处理的文件系统拒绝升级为全局 Unhandled Runtime Error。子目录沿既有 FileTree 错误及重试状态传播异常。

失败后不得自动循环请求；显式重试合并同列在途读取，成功后显示真实目录。切换 cwd、移除并重建列或重置 store 后，旧请求结果不能回填新列、覆盖错误或删除新请求的并发保护。保留 cwd、选择及展开状态；读取和重试不得创建 PTY、目录、工作区或写入 .ridge。

不改变操作者文件范围、原生及远程鉴权、协议或持久化格式。真实隔离 Kernel 原生 WebSocket 验收应证明允许目录可读、根外目录仍返回 outside_sandbox；实际生产 Explorer 与 FileTree 展示局部失败、显式重试和恢复，不显示假空目录或全局错误。覆盖中英文窄栏、连点、失败后成功、同路径列重建与迟到响应；回归 npm test、lint、typecheck。截图中的字体初始化另属 CHG-133。

依据：用户报告文件树 RpcRemoteError，已授权继续修复。只读取证：正式 Kernel 当前 D:/go-learn 及 C:/code/wind 首层可读；截图实例同一二进制在隔离原生 WebSocket 中，允许根及 workspace 可读，C:/code/wind 合法拒绝。原报错请求路径未被旧界面保存，不伪称已确认。当前源码将读取失败转为假空目录并触发全局错误，此缺口可直接复现。
