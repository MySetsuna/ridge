# Honor WebGL2 surface limits without panicking

The WebGL2 device request kept the portable 2048 texture-dimension default
even when the adapter advertised a larger render target. A desktop shared
surface therefore panicked at 3100x1348, while mobile viewports happened to
fit.

## Acceptance

- Device negotiation adopts the adapter's texture resolution limits and still
  clamps every other requested maximum to supported values.
- Surface resize validates its backing extent before `wgpu::Surface::configure`
  and returns a structured initialization error instead of panicking.
- Failed initial resize releases the half-attached host; canvas dimensions and
  styles roll back on any resize rejection.
- WebGPU desktop, WebGL2 fallback, and mobile Remote fixtures retain their
  existing renderer API and behavior.

Describe the approved semantic delta and its acceptance tests.
