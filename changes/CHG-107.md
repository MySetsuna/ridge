# 修复 Linux Agent 发现误用截断进程名

0.1.98 桌面 CI 与本机 Linux 均复现 Commune 组织登记测试在发现阶段超时。sysinfo 默认刷新已读取 exe，但未读取 cmd；Linux name 为截断后的 comm，当前快照丢弃完整 exe，长文件名无法匹配已配置进程。使用已读取的完整执行路径，读取不可用时保留原 name 回退，不扩大命令参数采集，不放宽进程实例或端点归属校验。以同一真实长名进程、PTY、端点和原会话的组织登记测试做 Windows/Linux 回归。
