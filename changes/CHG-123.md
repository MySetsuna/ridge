# 固定协议源的可重现检出并强制发布前漂移验证

现有 CI 缺少协议源时，漂移守卫四项跳过后仍成功。另查明 SOURCE_REV 对应本地已提交、尚未推送的协议源码。已在独立 codex/terminal-input-identity 分支公布原提交并补齐文本 hex fixture 的 LF 检出属性，Rust 协议回归 40 项通过，协议 Git blob 与现有 vendored 内容一致。将 SOURCE_REV 更新至仅补检出属性的新固定提交，保持协议模型与字节语义。发布与 release 测试从 SOURCE_REV 读取、校验并检出公共协议源，CI 缺源直接失败，继续执行既有逐字节对照。正常发布增加协议漂移检查，回滚与复用产物流程沿用原路径。通过缺源、篡改、固定源正向对照及实际 GitHub 发布取证。
