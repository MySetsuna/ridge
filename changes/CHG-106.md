# 修复 Cloud 移动端重连鉴权前误发工作区请求

公网主机重连已能重建 RTC，但移动端在重新鉴权前发布 connected，使页面立即查询工作区、终端及尺寸；新主机会话尚未授权，请求失败后页面丢失活动终端。保持重连状态直到新代际鉴权成功，先清理旧订阅，再开放页面请求与重订阅。失效、撤销或旧代际授权均不得开门。补延迟授权、失败和重复断线回归，并重新执行公网主机重连与原终端输入验收。
