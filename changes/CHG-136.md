# 修复 Remote 创建终端回包覆盖后续导航

沿用已批准的工作区隔离与导航代次契约。冻结创建目标，防止迟到成功或失败污染后续选择；覆盖 MainApp 与工作区树、LAN 与 Cloud。精确原函数失败证据见 artifacts/docs-mapping-integration/remote-create-navigation-race.json。

提案先入队，待 CHG-133 原生恢复验收及闭环后再审批加锁实施，避免并行覆盖其文件。验收覆盖正常创建、延迟回包、切工作区、同工作区换 pane、A→B→A、连接替换、目标消失、宿主拒绝、重复点击及原 PTY 身份；实际生产入口与两种传输分别验证，不以 mock 冒充端到端。
