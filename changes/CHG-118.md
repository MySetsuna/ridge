# 保留 Cloud 工作区 pane 快照并防止元数据刷新清空终端选择

公网移动端手动刷新后，Cloud 适配器从工作区快照丢弃 panes，晚到的工作区元数据把当前 pane 清空，真实 Kernel 仍有两个活跃终端。保留已有嵌入快照，并统一刷新、启动恢复及推送的选择收敛。缺少 panes 表示快照未携带该字段，沿用同工作区已确认的 pane 投影或当前选择；显式空数组才清空。跨工作区不得沿用原 pane。定向回归覆盖 DTO 保真、元数据晚到、显式空列表、已关闭 pane 和跨工作区；公网复验刷新及尺寸切换、真实输入与画面，全量测试和 SpecTree 门禁照常。
