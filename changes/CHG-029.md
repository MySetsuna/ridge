# Preserve native-size color emoji overflow

The shared WebGPU glyph atlas currently scales color emoji into a one-em box.
That changes the Host system-font bitmap and makes emoji smaller than their
native terminal rendering. Keep the complete rasterized Host bitmap at its
native device-pixel size; its quad may overhang the cell allocation and must
not be clipped or rescaled to fit.

Acceptance:

- A color emoji quad larger than its reserved cell keeps its native width and
  height and uses the complete atlas UV range.
- A non-square color emoji keeps its native aspect ratio without centering
  or shrinking it into the cell box.
- Real WebGPU emoji output remains color, untruncated, and uses Host-provided
  font data in desktop, Remote, and Cloud paths.
- Focused Rust/TypeScript tests and the STC verification gate pass.
