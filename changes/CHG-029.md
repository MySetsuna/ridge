# Remote 体验修复 Beta

## 背景

- 旧规则：Remote 默认按 UA 分流——桌面浏览器拿桌面 SPA，手机浏览器拿手机 SPA。
  与「所有设备默认手机端 UI」的目标相反。
- 桌面 Web Remote 在电脑浏览器上把虚拟键盘栏永久钉在标题栏，浪费空间且触发误触。
- 旧代码 `?ui=foo` 这类垃圾值仍被传给 `prefer_desktop_ui`，等价于无覆盖，
  桌面 SPA 可能在用户手滑时被误升。

## 变更

### SSOT 翻转（packages/ridge-remote/src/ua.rs）

- `prefer_desktop_ui(ua, override)` 不再嗅探 UA；仅在 `override == Some("desktop")` 时
  返回 `true`。其它情况（无 override / `?ui=mobile` / 任意 UA / 任意窗口宽度 /
  任意历史偏好）一律返回 `false`（手机 SPA）。
- 移除 `MOBILE_UA_MARKERS` / `is_mobile_ua`（UA 嗅探仅服务于旧默认，已无外部调用方）。
- 新增 `parse_ui_override(raw: Option<&str>)`——只把 `desktop` / `mobile` 收成有效值，
  其余视为 `None`，防止垃圾值把桌面 SPA 误升。
- 单元测试 4 条 + 集成测试 7 条覆盖新规则、垃圾值、跨形态资产回退。

### 桌面 Web Remote 的手机端 SPA 适配（src/remote/lib/deviceClass.ts）

- 新增 `readDeviceClass()` 与 `watchDeviceClass(cb)`——基于
  `(pointer: fine) ∧ (hover: hover)` 判定「是否带实体键盘」。
- `MainApp.svelte` 接入 `hasRealKeyboard` 状态：
  - 实体键盘设备上**不**显示虚拟键盘按钮 / 虚拟键盘栏；
  - 触屏设备保持原行为不变；
  - 设备类变更（外接键盘 / 折叠屏切换）实时响应；
  - 关闭对 `VirtualKeyboard.svelte` 的 lazy-load（省 chunk + 减初装体积）。
- 7 条单元测试覆盖默认、组合查询、SSR/无 window 兼容、Safari < 14 兼容。

### 既有 e2e 钉（packages/ridge-remote/tests/ua_fork_serve.rs）

- 主钉改名 `default_ui_is_mobile_regardless_of_ua`：所有 UA 默认拿手机 SPA；
- 显式 `?ui=desktop` 才能切桌面；
- 垃圾 `?ui=foo` 回退默认；
- 跨形态资产回退仍生效（`?ui=desktop` 后拉 `_app/*` 资产不带覆盖参数 → 必须跨形态拿到）；
- 路径穿越守卫 / SPA 路由回退不变。

## 兼容性

- 原生 Ridge Desktop（Tauri shell）不受影响——它不走 `ridge-remote::serve` 链路。
- 桌面 Web Remote（`?ui=desktop`）继续以 SvelteKit `_app/immutable/*` 提供。
- 已有 `?ui=desktop` 链接（含 E2E 工具脚本 / 排障手册）继续工作。
- 既有 `?ui=mobile` 显式覆盖继续工作。
- 既有 iOS / Android Add to HomeScreen 入口继续工作（manifest 不变）。

### 顺手抓的真实协议 bug（实 LAN Host 端到端验证中发现）

- `packages/ridge-cli/src/kernel_host_impl.rs:488` 的 hello 帧在修复前**漏发**了
  `terminalProtocolVersion` 字段。SPA 端 `packages/remote/src/shared/transport/wsRemote.ts:1015`
  的严格 `terminalProtocolVersion !== 2` 校验会因此误报"Remote 主机终端协议过旧"，
  让 §4 发布门槛的"无认证、错发输入、重复输入、会话误绑定问题"失守。
- 修复：在 hello 帧里加 `"terminalProtocolVersion": ridge_term::terminal_v2::PROTOCOL_VERSION`，
  与 `tui/lan_host_impl.rs` 同一常量保持一致（值 = 2）。
- 验证：真 `./target/debug/ridge.exe host --port 5001` + Chrome DevTools MCP 走通
  TOTP → WebSocket → PTY 真实往返；终端面板出现 bash 历史并响应虚拟键盘 Enter 输入。
