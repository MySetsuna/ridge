# Unify terminal cell graphic presentation

Rounded corners currently split one selected-font bitmap into a main quad and
a one-device-pixel edge quad. That second triangle strip creates an independent
rasterization boundary at the cell edge; the enlarged Windows reference shows
one missing pixel at that boundary even though the source edge texel is opaque.

Render every terminal cell graphic, including Box Drawing and Block Elements,
as one WebGPU quad. Extend only Unicode-declared connected sides in the
selected system-font raster, while snapped cell clipping chooses the visible
native texels. Do not scale the bitmap, add geometric lines, or duplicate alpha
at the join. Ordinary text and color emoji remain on their existing paths.

Acceptance:

- At the active Windows configuration (Consolas, 32 px, DPR 1), all four
  rounded corners meet adjacent straight glyphs without a missing pixel.
- Each rounded glyph emits exactly one atlas instance; no connector edge strip
  introduces an independent rasterization or blend boundary.
- Rounded curves keep one-source-texel-to-one-device-pixel nearest sampling.
- Straight and rounded connector profiles remain aligned at both axes.
- Block Elements used by RidgeCode and Claude Code logos tile continuously
  across adjacent columns and rows without changing their internal shapes.
- Focused atlas/rasterizer tests, complete `ridge-term` tests, and Remote WASM
  production builds pass.
