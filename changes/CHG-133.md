原生保活验收复现：字体枚举接近 5 秒默认 RPC 读时限；首次初始化失败后，终端仍活跃但 RidgePane 永久不附着。公网手机验收又确认 scoped Git 读命令可从授权子目录走到根外父仓库；写操作已有保护。另 Commune 历史查询实际聚合全部工作区，但空态文案仍称此工作区。按既有修复、E2E 与元数据例外授权，在独立 Git worktree 走完整门禁。

仅扩大只读字体清单请求的有限时长；失败后有界重试及显式恢复，重复点击不得重建 PTY 或重复绑定；卸载后不得继续附着。Git 共同 admission 校验实际仓库根，限定 roots 下读取与发现不得向父仓库逃逸；授权范围内的子目录和仓库仍可正常读取。保留既有写保护及空目录语义。历史只修正全局空态，不改查询、协议或存储。
