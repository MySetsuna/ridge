# Harden deterministic weak-network evidence validation

## Semantic delta

- Emit `evidenceScope: deterministic-lab-only` in weak-network metrics.
- Validate the machine scope instead of localized disclaimer wording.
- Keep a non-empty human disclaimer mandatory.
- Invoke pnpm through its JavaScript entry point without `shell: true`.

## Acceptance

- Validator unit tests reject missing scope, short matrices, and malformed rows.
- `node scripts/run-weaknet-lab.mjs` passes all nine deterministic scenarios.
- The run emits no shell argument-concatenation warning.
- The artifact remains explicitly ineligible as physical-device evidence.
