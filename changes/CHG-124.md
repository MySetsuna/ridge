# 修复 Remote 目录作用域、Cloud 分屏切换与 Commune 导航

落实用户已批准的目录与 Commune 界面草案；合并旧隔离草案的目录作用域、Cloud 分屏订阅和手机编组导航，避免与主仓已占用变更编号冲突。

保留独立终端、工作区授权、派发确认及 revision 契约。Grok 实机验证按用户指示跳过，不能标为已通过；不属于本次三项验收。

验收覆盖真实隔离 Kernel 的 LAN／Cloud 目录切换、无 PTY 分屏与连接连续性、手机编组导航及既有派发操作，并执行仓库检查和 SpecTree 门禁。
