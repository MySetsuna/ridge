# Remote desktop and mobile input fidelity, bounded delivery and lazy runtime recovery

Repair desktop/Remote input and bounded delivery/recovery; unify cursor and link ownership in ridge-term; add semantic row demand loading and independently loadable terminal WASM modules; default all Remote browsers to the simple UI, with explicit ui=desktop opt-in. Acceptance is defined by the two affected nodes in the companion proposal. This remains an implementation change until the complete runtime, performance and deterministic gate evidence exists.
