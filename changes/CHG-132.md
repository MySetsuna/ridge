# 固定桌面发布编译器，避免 Cargo 目录布局漂移破坏 sidecar 打包

0.1.101 发布 run 43885348752 使用浮动 stable，实际升级到 Rust/Cargo 1.100.0。新的 OUT_DIR 布局使 tauri-build 2.6.2 把 target/debug/build 当目标目录，试图删除其中 ridge-mcp crate 目录而失败。固定本次桌面发布与门禁所用编译器为上一轮四平台成功 run 42802646994 实际使用的 1.99.1；不删除 Cargo 目录、不跳过编译或测试、不改既有 tag。保留当前 CHG-131 并行归档工作，本提案在独立 Git worktree 中 apply 并取得自己的锁，不改并行工作区锁状态。复用现有授权与 change 元数据例外。最终以实际固定工具链、完整测试门禁与四平台构建结果验收，未成功不得称已出包。
