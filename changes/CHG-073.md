# Ridge workspace and Commune visual system

Refresh the desktop workspace tabs and Commune surfaces as one coherent Ridge interface. Workspace tabs expose unread Agent activity and clearly distinguish transient workspaces from named local saves; only named local saves participate in restore. Commune member, history, and group/task surfaces remain reachable and functional through their actual Runtime execution paths.

Use a restrained Ridge forest-green accent, neutral surfaces, deliberate typography and spacing, and precise industrial details. Preserve the active light/dark theme, keyboard access, focus visibility, responsive layout, and all existing workspace, membership, task, approval, history, and terminal semantics. Remove no user capability and do not infer task completion.

Acceptance: test unread workspace notifications and saved/temporary restore behavior; exercise member, history, group/task, and approval surfaces through production components; verify the visual system in both supported themes and at desktop/narrow widths; run npm test, npm run lint, npm run typecheck, and SpecTree verify.
