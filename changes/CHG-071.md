# Workspace recovery, attention and Commune interface

Separate presentation startup recovery from the Kernel's live runtime. Closing the desktop detaches the UI while the Kernel, PTYs and running Agents remain alive. Reopening attaches to existing runtime entities; the file recovery set contains only existing, valid, named, locally saved `.ridge` workspaces. Temporary workspaces do not create `session-*.ridge` files or user restore-index entries, and saved workspace metadata does not claim to resurrect a terminated PTY.

Add workspace-scoped Agent message attention to workspace tabs; complete workspace and Commune i18n; make Commune history and reply views refresh from correctly workspace-filtered events; improve hierarchy and readability while retaining existing protocol, group, approval and message behavior.

Acceptance: verify real Kernel/PTy lifetime across desktop exit and reattach without duplicate processes; verify restore filtering and absence of temporary session exports; exercise per-workspace unread attention, event-driven history refresh, messages, groups, approvals and cross-workspace isolation; verify supported languages and review the redesigned workspace/Commune UI. Run repository test, lint, typecheck and SpecTree gates.
