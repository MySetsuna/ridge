# Scope semantic ownership by integration area

## Semantic delta

- Move script ownership from the root into an automation area.
- Keep generated CSP ownership with the web application shell.
- Isolate desktop host-to-Remote imports in a host integration area.
- Isolate Commune-to-Remote HITL imports in a dedicated bridge.
- Remove root dependencies that made one Remote evidence change stale every
  project node.

## Acceptance

- `stc validate` reports a valid acyclic graph.
- `stc audit --all` reports no findings.
- Active Remote evidence changes stale only actual dependents, not all nodes.
- Existing source and tests remain unchanged.
