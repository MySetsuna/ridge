# Claim mobile remote grid after resize binding

The mobile terminal currently attaches and performs its first local fit before
registering the callback that claims the Host PTY. Its later fit sees identical
rows and columns and returns as a no-op. The browser kernel therefore parses a
narrow mobile grid while the Host TUI keeps emitting against its previous wide
grid, turning in-place redraws into wraps and scrollback.

After the resize callback is registered, force one same-size fit through the
normal Remote-owned claim path. The browser kernel is sized before the claim,
and the Host PTY plus canonical parser then receive the same rows and columns.

Acceptance:

- A cold mobile attach sends one Host resize claim even when the local attach
  fit already produced the same rows and columns.
- The forced fit uses the measured pane box and keeps owner `remote`.
- Same-size ResizeObserver noise remains debounced; only the post-binding cold
  claim and explicit refresh bypass equality suppression.
- A deterministic test proves the resize handler runs for a same-size forced
  shared-remote fit.
- Remote unit tests, production build, and STC gates pass.
