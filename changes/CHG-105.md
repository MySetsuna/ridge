# 修复主机重入信令房间后旧加密通道假在线

用户要求完成真实公网 E2E 后交付。强制 TURN 的公网验收复现主机离开并重入信令房间后，Remote 沿用旧 RTC/E2EE 会话，界面假在线且输入无响应。主机离线须结束旧传输并按既有退避重建完整加密会话，不能只重用 ICE 或丢弃错误。维持正常信令单独断开而 RTC 仍健康时的现有行为。新增状态回归与真实浏览器/Kernel 主机重连验收，原终端进程不变；再重新发布 Remote 并在公网验收。
