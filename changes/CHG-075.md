# Isolate browser E2E runtime bootstrap

Playwright's browser-only E2E server must use a dedicated Vite mode that mounts the application without attempting the native Tauri Runtime grant handshake. Keep the mode scoped to the Playwright webServer command; normal Vite, native desktop, and web-remote boot behavior remain unchanged.

Acceptance: `npm run e2e -- tests/e2e/commune.spec.ts` starts its own server, reaches the production Commune UI without `window.__TAURI__`, and passes all three existing tests. Run the full E2E suite, `npm test`, lint, typecheck, and SpecTree verify.
