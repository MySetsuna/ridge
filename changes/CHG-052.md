# Remote Release Gate: closeout umbrella — writePty composite-key fix + lock catch-up

## §1 Semantic delta

This Release Gate change closes out the accumulated Remote delta since the
CHG-045 lock. The intermediate deliverables (CHG-050/051 work: workspace/
pane ownership refresh, wgpu per-canvas surface fix, MainApp stale-pane
gating, AVD evidence scripts/docs) were approved but never re-locked; the
lock baseline is therefore swept up here together with the CHG-052 core
fix. Affected nodes cover exactly the drifted surface.

**writePty composite-key fix (CHG-052 core):** `TerminalManager`
`_installAttachDebugHooks.writePty` (E2E/test harness entry) forwarded its
`paneId` argument verbatim to `invoke('write_to_pty', …)`. Manager pane-map
keys are composite `workspaceId:paneId` strings (73 chars) while the Tauri
command parses `pane_id` with `Uuid::parse_str` (36-char bare UUID) and
rejects composite keys with `invalid pane id: invalid length`. The fix
extracts the bare pane UUID (segment after the first `:`) before invoking;
bare-UUID callers pass through unchanged. Production input path
(`paneInputGate` → `PaneRpcScheduler` → transport) is untouched — no
transport / auth / wire-contract change.

**Spec bookkeeping:** L3-OBS-REMOTE-RESUME-MD (docs ownership) gains the
three `docs/architecture/notes/*` acceptance docs + `FINAL-REPORT-A8.md`;
L4-OBS-CLAUDE-SETTINGS-LOCAL-JSON gains `.gitignore`; L2-REMOTE-MOBILE-
SEMANTIC-V2 gains `scripts/browser-ui-e2e.mjs` as test target;
L4-OBS-SRC-REMOTE-LIB-TERMINALCANVAS-SVELTE `public_interface` is re-synced
to the post-closeout exports (adds `applyRemoteFrameForPane`,
`claimPaneSize(): Promise<void>`).
