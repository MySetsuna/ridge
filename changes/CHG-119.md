# 完整缓冲 Remote 初始化输入并约束终端生命周期切换

公网已复现首字符在附着前缓冲，后续字符在附着后因 terminalInputContext 缺省而丢弃，形成残缺命令。统一有界键盘缓冲，保留文本和特殊键顺序，在规范上下文及锚点就绪后排空；物理键盘和 IME 保持捕获，虚拟键、粘贴和鼠标保留既有未就绪保护。快照到来须主动推进排空，即使光标位置不变。缓冲绑定已观察的终端 epoch，换代、溢出和卸载整批丢弃并阻止隐式尾部重放。单元回归覆盖空上下文、延后编码、同 epoch 新激活、换代、溢出、重试及取消；真实浏览器加真实 Kernel/PTY 通过可控附着与上下文延迟验收整条命令只执行一次，再运行全量工程门禁。
