# 清理终端视口移动收缩后的残影并同步当前帧失效状态

公网主机重连及多端尺寸切换后，移动视口从宽网格居中为窄网格，旧区域文字残留。实际仅重绘 pane 能更新内部内容，清理共享 host 后旧区域才消失。_recomputeViewport 更新偏移和大小时未使旧表面失效，且 RAF 在几何变更前读取失效标志。修复共享视口变更的结构失效，并在本帧几何收敛后消费标志，使邻接 pane 同帧重绘。定向回归覆盖变更失效、相同几何零额外清理及本帧重绘标记，再复核公网画面和真实输入；早期输入就绪时序单独取证。
