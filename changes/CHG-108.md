# 补齐 Linux Agent 发现的真实进程观察回归

Linux 真实取证确认 sysinfo 将线程放入 processes 集合，线程与主进程具有相同完整 exe。现有“有同名子进程则视作包装器”规则因此排除真正 Agent，线程自身又因内核进程归属校验不符被拒绝，导致发现为空。进程快照仅保留真正进程，按平台 API 排除线程，保留原 PID/启动实例及所有权校验。Windows 与 Linux 的现有真实组织登记回归均须通过，不增加超时、不忽略测试。
