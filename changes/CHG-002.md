# 當前 remote 還是不可用，需要修復

桌面 Remote 驗證請求須攜帶與 WebSocket 相同的瀏覽器裝置標識，修復 token 因裝置綁定不一致而遭拒。

驗收：桌面與手機 Remote 的 `/verify` 請求均含 `device`；嚴格綁定不降級；Remote 構建、相關測試與全量工程門禁通過。
