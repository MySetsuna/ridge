# 约束原生与 Web 构建的终端剪贴板来源并消除条件漏测

现有终端图片剪贴板测试按构建标志跳过另一分支，默认 npm test 因而只执行原生分支。Vitest 将自定义 import.meta.env 定义转为字符串环境值，无法代表生产构建中的布尔常量。以真实 Vite 编译分别生成原生与 Web 产物，再用隔离的系统剪贴板、浏览器剪贴板及主机保存端口替身验证已有来源边界、事件图片、拒绝授权与保存失败。两种产物均由默认测试命令执行，测试中不再以当前构建标志跳过任一来源分支。正常新构建的 Remote 发布在产物构建与上传以前运行同组回归，失败即停止发布，现有回滚及直接复用产物流程沿用原路径。当前源逻辑及 0.1.100 已发布产物沿用原实现。真实设备权限与公网闭环继续单独验收。
