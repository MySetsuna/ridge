# Remove residual monochrome coverage haze

The prior centred coverage transfer improved terminal text, but retained a
visible grayscale fringe at 15 CSS pixels. Narrow the monochrome transfer to
near-binary coverage while preserving system-font geometry and color emoji.

## Acceptance

- DPR 1 WebGPU and WebGL2 fixtures retain complete system glyphs with at least
  95% solid monochrome coverage and at most 5% transition coverage.
- DPR 1.25 retains complete CJK, symbol, emoji, and grapheme-cluster rows.
- Color emoji alpha, system CSS fallback, nearest atlas sampling, and GPU
  presentation remain unchanged.
