# 保留 Remote 刷新凭证并初始化首屏键盘避让

Remote PWA updates invalidate application caches without deleting LAN tokens,
Cloud controller trust identity, or unrelated browser data. Refresh therefore
reuses the existing authorization until its normal expiry or explicit logout.

The first mobile terminal pane captures its resolved IME cursor anchor on the
trusted tap path before focusing the hidden input, then recomputes avoidance as
the VisualViewport changes so the active input row remains above the keyboard.

## Acceptance

- LAN token and Cloud trust identity survive page refresh and PWA cache updates.
- Explicit logout and confirmed authorization failure still remove credentials.
- The first pane tap captures an IME anchor before focus.
- Opening the keyboard recomputes terminal shift after focus and viewport change.
- Existing Remote tests, build, lint, typecheck, and SpecTree verification pass.
