# Bound terminal CDP probe requests

## Semantic delta

- Abort stalled CDP target HTTP requests.
- Bound WebSocket opening and every command response.
- Remove timed-out requests from the pending map and clear timers on response
  or transport teardown.
- Capture WebView2 through one bounded, acknowledged screencast frame because
  its screenshot command can remain pending forever; preserve crop and scale.

## Acceptance

- A stalled command exits with its CDP method name instead of hanging.
- Fixture-only rendering completes or returns a bounded diagnostic.
- Successful terminal rendering behavior remains unchanged.
