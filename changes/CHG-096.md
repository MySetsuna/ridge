# 为 Remote 编辑器增加条件保存与冲突保护

落实审核中已复现的陈旧保存覆盖问题。Remote 编辑器携带最后确认的原文快照调用新增条件保存命令。Runtime 内文件变更互斥，旧快照冲突返回明确错误并保留手机草稿；回执丢失后已写入相同正文可确认成功。保留既有两参数写接口，旧 Host 不支持新命令时禁止退回无条件覆盖。
