# 登录与设备配对轮询遇限流后保持可恢复

真实登录等待中出现 RATE_LIMITED。服务端认证桶为每 IP 每分钟 10 次，而登录轮询建议 2 秒；原客户端一遇 429 即终止，尚未批准的正常登录因等待时间而失败。仅对明确拒绝的登录/设备轮询退避并降低后续频率，保留浏览器批准所需余量。重用同一授权请求与配对码，沿既有总期限和取消路径退出；其他错误继续传播。回归覆盖退避、取消、到期及凭据创建次数，运行全量工程门禁。
