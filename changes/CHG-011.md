# Negotiate terminal GPU device limits

## Semantic delta

- Clamp every requested maximum to the selected adapter's advertised value.
- Adopt adapter-required buffer alignments.
- Keep negotiation host-testable through wgpu's shared `wgpu-types` contract.
- Authorize the workspace lockfile and render-module registration changed by
  that shared type module.
- Reject an adapter below the glyph atlas's 256-layer floor before device
  creation.

## Acceptance

- Native tests cover a browser adapter exposing six color attachments.
- `cargo test -p ridge-term --lib` passes.
- Mobile LAN E2E initializes WebGPU without `LimitsExceeded`.
- Forced WebGL2 mobile E2E uses the same renderer and passes.
