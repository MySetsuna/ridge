# CHG-059 — M4 Live Provider + Desktop Productization

## §1 Scope

- `ProviderKind::OpencodeAcp` new variant (explicit real-binary provider)
- `provider_adapter.rs` — `resolve_provider_launch()` maps `ProviderSpec → SpawnSpec`
  with binary + framing + model/effort args; honest `CapabilityGap` on missing binary
- Bridge `spawn_one_session` now calls `resolve_provider_launch` instead of hard-coded
  `opencode-acp` / `fake_acp_agent` lookup; supports `Mock / Anthropic / OpenAi / OpencodeAcp`
- `AgentSessionPicker.svelte` — Desktop provider / model / effort selector
- `DefaultWiredAgentChat` exposes `picker` slot for the selector to mount alongside chat
- `acp_session_status` now includes provider spec for restore-driven UI

## §2 NOT in scope

- Runtime / Remote / Kernel / RTP1 / PTY / terminal renderer / replay / resync
- Removing legacy `read_agent_recent_replies` / `resume_agent_session` (M3 §2 rule)
- Removing legacy `AgentCenterPanel` (target: migrate callers, not delete)
- Direct Anthropic SDK / OpenAI SDK wiring (still NEXT_SLICE — opencode-acp proxy)

## §3 Acceptance

1. `cargo test -p ridge-acp --tests` — 50+ tests pass; 4 new provider_adapter tests
2. `cargo check -p ridge` — clean (91 pre-existing warnings unchanged)
3. `acp_open_session({ provider: { kind: 'anthropic', model: { id: 'claude-haiku-4-5', effort: 'high' }, config: {} } })` — spawns opencode-acp with `--model claude-haiku-4-5 --effort high`
4. `acp_open_session({ provider: { kind: 'mock' } })` — still spawns `fake_acp_agent` (CI fixture)
5. Capability gap on missing binary surfaces as Rust error → Tauri command error → UI
6. API key never in `AgentSessionEvent` payload (verified via ProviderSpec `config` not in event structs)
