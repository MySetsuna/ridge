# CHG-060 — M4.1 commutation_event rendering + Lead+2 Staff flow

## §1 Scope

- `agentEvents.ts` adds `CommutationEvent` tagged union (mirrors Rust)
- `reduceEvent` dispatches both `AgentEvent` and `CommutationEvent`
- `DefaultWiredAgentChat` listens for `commutation_event` Tauri events
- `AgentChatPanel` renders `commutation_created` / `staff_assigned` /
  `staff_progress` / `staff_completed` / `staff_failed` / `handoff` /
  `lead_final` as inline plan/task/staff lines
- New Tauri commands:
  - `commutation_open_with_text(text)` — wraps `commutation_open` and
    immediately fires `commutation_prompt_lead`
- `Commutation::lead_final_aggregate` payload structure (M4.1 §5):
  - handoff carries `staff_id + result_payload`
  - `lead_final` carries aggregated summary across staff_ids
