# 串行 Remote 尺寸刷新与当前屏重同步

Remote 刷新须与桌面单 pane 刷新同义：按当前 pane 实测尺寸强制宿主重排，
等待 resize 确认后，方清除旧尺寸队列并请求当前可见屏的完整重同步。

## Acceptance

- `TerminalManager.claimPaneSize` 返回宿主 resize callback 的完成 promise。
- Remote canvas 的 `claimPaneSize` 等待该 promise 后才完成并触发本地全绘。
- MainApp 既有 `await claimPaneSize` 严格先于清旧帧与 `resyncPane`。
- 同尺寸刷新仍强制执行；既有一次自愈重试保留。
- 定向测试、全测、检查、Remote 双构建及 SpecTree 验证通过。
