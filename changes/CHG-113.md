# 以 CSSOM 接通 Monaco 主题、动态样式与严格 CSP

公网文件编辑器创建动态 style 元素触发严格 CSP；现有 MutationObserver 在拦截发生后补样式，仍产生违规且无法覆盖所有动态规则。复用现有 CSSOM 样式路径，在 Monaco 创建样式时接入受信样式表，覆盖主题、动态规则、ShadowRoot、克隆和释放。保留原 CSP 与权限；真实 Chromium 验证输入、diff、换肤、生命周期及未授权样式仍遭拒绝，构建钩子漂移须明确失败。
