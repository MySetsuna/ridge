# Align terminal box connector axes and coverage

The box-drawing quad currently maps every source column into each snapped cell
width. Fractional-DPR grids alternate physical widths, so nearest sampling picks
different source columns for otherwise identical cells. Vertical extensions
also derive their top and bottom profiles independently, exposing different
Swash coverage values at row joins.

Box-drawing must retain a one-source-texel-to-one-device-pixel mapping. Clip its
native bitmap and UV rectangle to the snapped cell bounds instead of rescaling
the full bitmap. When one glyph connects through both vertical cell edges, use
one stable selected-font connector profile for both extensions. Preserve native
curve pixels and keep color emoji geometry unchanged.

Acceptance:

- A narrower snapped cell crops the box bitmap UV at 1:1 density; it does not
  compress the complete source width.
- Box quads clip native left/right overhang and top/bottom overflow without
  scaling either axis.
- A vertical connector fixture with different native first/last profiles emits
  identical top and bottom extension coverage from one stable profile.
- Real Consolas straight and rounded box glyphs remain monochrome Swash rasters
  whose declared connector edges contain coverage.
- Ridge-term WebGPU tests, WGSL/native build, WASM build, and STC gates pass.
