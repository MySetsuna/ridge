# 修复 Remote 桌面窗格启动超时黑屏并后置历史预取

正式 0.1.99 安装包公网 E2E 中，UDP 中继启动 RPC 超时后，RidgePane 在 create_pane catch 直接返回，未注册快照，也未呈现重试入口；历史预取又排在关键启动请求之前。复用现有错误与 Retry 呈现，允许同一 workspaceId/paneId 重新执行幂等启动与快照订阅，保持原子进程。历史移至启动关键路径之后。通过顺序、失败、组件失效隔离测试及真实公网输入、刷新、主机重连验收；不增加超时、不重放终端输入、不终止正式终端。此轮仅发布 Remote 后续修复，保留 v0.1.99 安装包与 tag。
