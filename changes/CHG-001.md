# Agent activity Commune UX and runtime resource hardening

## Confirmed defects

- Cross-workspace topology refreshes evicted one another's signal-stability clock.
- Agent process discovery cached one pane-set result, so alternating workspaces
  repeatedly rebuilt the host-wide process table.
- Activity expiry depended on the Commune panel being mounted or a later event.
- An open Commune panel duplicated output-driven topology and approval reads.
- Member cards hid the latest reply and compressed identity and controls.
- Closing a Remote view parked terminal kernels but never detached them, while
  pane switch buffers, resync timers, and trace state survived pane retirement.
- Hidden sidebar panels were mount-gated but still statically imported, pulling
  SCM, Remote, Hosts, and Commune feature graphs into desktop cold boot.
- Local Playwright could silently reuse an unrelated app already bound to 5173,
  and its full-page readiness probe duplicated the cold application compile.

## Acceptance

- Output sequence and OSC title both participate in activity; a global delayed
  refresh settles working to idle even when Commune is closed.
- Clicking an Agent card or focusing its pane clears attention for that exact
  state, and no repeated snapshot re-arms it before a status transition.
- One process snapshot serves distinct workspace queries inside the 500 ms TTL.
- Commune consumes shared topology and the same approval response, avoiding a
  second routine layout/output topology refresh and duplicate approval IPC.
- Removing a workspace prunes topology, status, attention, acknowledgement,
  observation maps, queued refreshes, and expiry timers.
- The Agent sidebar opens at least 360 px wide; cards, typography, focus states,
  and persistent latest replies are materially larger and clearer.
- Pane, workspace, and Remote-view retirement clear every pane-owned queue,
  timer, trace, transport subscription, and terminal kernel; a cancelled queued
  resync cannot resurrect work after cleanup.
- Hidden heavy panels and the shared Remote surface are true dynamic imports;
  only the lightweight global Agent attention synchronizer remains eager.
- Playwright owns a strict, configurable loopback port, probes Vite readiness
  independently of app boot, and tolerates Vite's single cold reload.
- Svelte checks, focused Vitest contracts, and focused Rust tests pass.

## Implementation evidence

- `b4889d4f` introduced the shared activity data plane, process snapshot cache,
  lifecycle cleanup, demand-loaded panels, and their deterministic contracts.
- `de194255` prevents an acknowledged pane state from re-arming attention.
- `f2455a0a` and later Remote lifecycle tests cover terminal retirement and
  queued work cancellation.
- Focused frontend contracts pass 98 tests; Agent process discovery passes 14
  Rust tests, including two workspace consumers sharing one snapshot.

The public-network and physical-device soak required by
`L4-REMOTE-PERFORMANCE-GATE-001` remains follow-up scope in `CHG-002`; it is not
claimed as evidence for this change.
