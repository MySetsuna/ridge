# 修复工作区切换和分屏后的终端键盘焦点

依据用户持续授权修复终端无响应问题，补齐显式工作区切换、创建与分屏后的 DOM 键盘焦点；保留现有选中 pane，不改变 PTY 生命周期。仅在导航完成且用户未转入其他输入控件时恢复焦点，过期导航不能抢焦点。以原生 dev:cdp 真实界面复现和回归，另测编辑器及其他终端的焦点保护；不把测试环境的非 breakaway 模式计作生产 Kernel 保活验收。沿用已批准的 change 元数据补齐例外。
