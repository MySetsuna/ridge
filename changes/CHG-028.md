# Preserve native cell glyph silhouettes and settle TUI cursor presentation

Cell-graphic seam repair currently changes the source glyph: rounded corners
are translated against inferred axes, while Block Elements with different top
and bottom silhouettes reuse the stronger edge profile for both sides. This
turns asymmetric quadrant glyphs into the wrong shape and offsets corner arms.

Keep the selected Host font raster authoritative. Connected edges may repeat
the pixels already present on that same edge to fill line-height or cell-width
bearings, but must neither share a profile with the opposite edge nor translate
the complete glyph. This applies to every Box Drawing and Block Elements glyph,
so Claude, RidgeCode, and ordinary rounded frames use one path.

Codex startup also splits a synchronized repaint and its cursor-hide sequence
across ConPTY chunks. Keep the last presented cursor through the synchronized
output boundary until a 64 ms repaint quiet window expires; a later chunk
renews that window.

Acceptance:

- An asymmetric three-quadrant block keeps a full top edge and half-width
  bottom edge after connector completion.
- Rounded corners retain their native bitmap position while their declared
  arms still reach adjoining cell boundaries.
- Full, half, quadrant, and rounded fixtures remain seam-free in a real WebGPU
  WebView2 frame.
- A synchronized-output boundary cannot release cursor suppression before the
  quiet-window deadline.
- A real Codex startup trace never presents the cursor on its transient clear
  row before Codex hides or positions it.
- Focused Rust/TypeScript tests, WebGPU CDP fixtures, and STC gates pass.
