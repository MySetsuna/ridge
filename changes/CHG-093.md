# 修复终端 cd 后 pane header CWD 主动同步

用户报告终端执行 cd 后 pane header CWD 未同步。现有无 OSC 的 OS 目录观测只在 get_pane_cwd 请求时写回和推送，缺少 Runtime 主动观测。复用原精确进程绑定、根目录校验、事务写回和事件链补上 Runtime 观测，不增加客户端目录权威。
