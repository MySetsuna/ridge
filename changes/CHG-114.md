# 修复空 Runtime 首次启动工作区初始化

独立全新桌面配置稳定复现工作区空白。列表成功返回空数组后，refreshWorkspaces 继续请求 get_active_workspace_id；Kernel 合法返回 client workspace unavailable，导致 ensureActiveWorkspace 的权威空列表确认失败，无法进入既有新建路径。空列表刷新须成功结束，列表读取失败仍向上传播；不得在读取刷新中隐式创建工作区。沿既有启动流程创建唯一默认工作区，已有会话重连不得重复新建。覆盖定向回归、全部工程门禁及独立桌面 CDP 首次启动、刷新与终端输入。
