# 修复 Kernel 丢失 TURN 密码凭据类型导致 Cloud 会话无法创建

真实公网信令已确认 offer 发出但没有 answer 或公钥；服务端 ICE 配置含 TURN。Kernel 映射 RTCIceServer 时遗漏 credential_type，webrtc 0.11 默认 Unspecified，导致创建连接即拒绝 TURN 配置。补齐 Password 类型，并以含 TURN 的真实构造及浏览器/Kernel 链路验收，原 STUN-only fixture 不能覆盖此缺陷。
