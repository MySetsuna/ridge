# Document Remote and Cloud release operations

## Semantic delta

仓库须提供可复核的 Remote / Cloud 发布、回滚、在线验收及验证码信任故障排查说明。
说明不得包含 Token、Cookie、私钥或任何 Secret 值；仅记录 GitHub Secret / Variable
名称及工作流入口。

## Acceptance tests

1. 文档明确 Remote 静态产物与 Cloud 桌面安装包两条发布线的差异、入口、门禁及回滚方式。
2. 文档明确 `RIDGE_ARTIFACT_TOKEN` 只从 GitHub Secret 注入，`RIDGE_CLOUD_ARTIFACT_URL`
   从 GitHub Variable 注入，不要求或鼓励在本机查找 Token。
3. 文档明确 Release 工作流保持 `releaseDraft: true`，本轮仅生成草稿，不自动正式发布。
4. 文档记录 TOTP 信任授予后的 24 小时刷新 / 全量重连路径，以及失联重连的诊断顺序。
