# 清理现役规范及迁移基线的失效映射

用户要求将规范映射清理独立于 CHG-088 登记。本条为待评审的规格治理草案。

初始范围取当前 stc audit 报告的 180 条失效目标引用。affects 精确绑定报告涉及的节点。先核查现役规范，再核查历史迁移观察记录，逐条确定重绑定、退休或合并，保留原始证据。根据仍有效的要求和真实调用链确定实现及测试目标，归档旧实现用于溯源。

本条实施限规格与映射治理，implementation 为 NOT_REQUIRED。规格正文及映射调整经提案和 stc apply --confirm 应用。若核查发现需修改产品行为，登记对应实施变更再进入代码门禁。

验收保存逐项处置依据，确认目标路径存在、测试映射与具体要求对应、退休节点归档，运行图校验、审计及 SpecTree 测试门禁。其他审计告警须逐类保留或明确处理依据。
