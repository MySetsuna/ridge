# Repair SpecTree audit ownership and baseline

## Confirmed defects

- Eight directory literals matched no files and therefore authorized nothing.
- Generated coverage, test output, local tools, credentials, and editor state
  inflated the enforced baseline and produced 2,167 false uncovered findings.
- Existing `.gitignore` predated SpecTree and omitted its runtime build state.

## Acceptance

- `stc audit --all` reports no directory-target warnings.
- Generated and local-only paths do not enter the SpecTree baseline.
- Product source, tests, release workflows, and project documentation retain a
  semantic owner through L1 or a narrower child node.
- `.spectree/build` and secret-bearing OAuth state remain untracked.
- `stc validate`, `stc audit`, `stc coverage`, and the configured test command
  complete successfully. Audit retains only five pre-existing cross-level import
  warnings; declaring them would create forbidden parent/child graph cycles.
