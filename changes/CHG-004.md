# Remote 使用控制端系統字體

Remote 終端不得向 Host 請求或傳輸字體檔；應由控制端瀏覽器 Canvas2D 使用本機系統字體生成 WebGPU 字形圖集。桌面 Tauri 保留 Host/Swash 字體載入路徑。

驗收：Remote 初始化不呼叫 `load_terminal_font_faces` 或 `read_terminal_font_face_chunk`；Remote 可用系統字體初始化、渲染；桌面字體載入行為不退化。
