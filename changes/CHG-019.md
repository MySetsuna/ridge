# Remove terminal box connector seams and shadows

The prior box-drawing smooth-sampler branch scales one-device-pixel strokes and
creates gray shadows. Its connector extension also leaves already-painted,
low-coverage endpoint pixels untouched, so a dim notch repeats at every cell.

Box drawing must use the same native nearest atlas sampling as monochrome text.
For each Unicode-declared connector side, copy the selected font's stable
interior connector stripe through the logical cell edge, replacing both clear
and dim endpoint pixels. Preserve the remaining curve and intersection pixels.
Color emoji alone keeps linear sampling.

Acceptance:

- Horizontal connectors have identical premultiplied coverage through both
  logical edges, including fixtures whose original endpoints are nonzero/dim.
- Rounded corners extend only declared arms; non-connector curve pixels remain
  byte-for-byte unchanged.
- Production instance modes select nearest for monochrome text and box drawing,
  linear only for color emoji, and direct fill for solid rectangles.
- A real installed Consolas raster fixture proves straight and rounded box
  glyphs resolve through Swash as monochrome font bitmaps.
- WGSL, native renderer, Host font, and WASM build gates pass without Canvas2D.
