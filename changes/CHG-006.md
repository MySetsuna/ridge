# 修正桌面安裝包 docs 資源來源

桌面 bundle 的文檔資源來源須指向納入版本控制的 `docs/`，不得依賴不存在的
`static/docs`。安裝包內目標仍為 `static/docs`，不改運行時查找路徑。

## Acceptance

- `cargo check` 不再因 `resource path '..\\static\\docs' doesn't exist` 失敗。
- NSIS release 安裝包成功生成，且包含 `static/docs` 資源。
