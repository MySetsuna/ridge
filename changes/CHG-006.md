# Sharpen monochrome terminal glyph coverage

## Confirmed defect

At DPR 1, system-font bitmaps from browser Canvas2D contain a broad grayscale
antialiasing fringe. The atlas and glyph quads preserve a native 1:1 mapping,
so nearest texture sampling correctly reproduces that fringe, but terminal text
still looks softer than native DirectWrite terminal output.

## Semantic delta

- Apply a bounded contrast curve to monochrome glyph coverage in the shared
  WGSL compositor.
- Keep the 0.5 coverage boundary stable while suppressing low-coverage fringe
  pixels and strengthening high-coverage stroke pixels.
- Preserve color emoji pixels and alpha, glyph geometry, cell widths, atlas
  UVs, font fallback, and the WebGPU/WebGL2 backend selection unchanged.

## Acceptance

- WGSL validation and ridge-term tests pass.
- The DPR-1 native glyph fixture reports a higher solid-pixel ratio than the
  recorded pre-change baseline without changing row or cell geometry.
- WebGPU and WebGL2 screenshots retain complete CJK, symbols, box drawing, and
  color emoji with no clipping or runtime GPU errors.
