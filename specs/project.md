# Ridge

Ridge is a native terminal workbench built on Tauri v2 with a Rust backend and Svelte 5 frontend. It provides independent PTY panes, recursive split layouts, WebGPU terminal rendering, persistent workspaces, editor and Git tooling, search, and local or remote collaboration. Portable domain, terminal, tmux, MCP, and remote logic lives in Tauri-free workspace packages reused by desktop and headless hosts.
