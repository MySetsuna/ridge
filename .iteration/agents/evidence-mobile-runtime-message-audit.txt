DIAGNOSIS
The exact Chrome warning requires an Extension Messaging listener which retained a
response channel (return true or equivalent) and then lost that channel before a
response. The audited Ridge mobile Remote sources own no such listener or sender.
Ridge's PWA service worker Client.postMessage is a different Web API and cannot
produce that chrome.runtime response-channel warning.

Code ownership is therefore disproved for the audited source. The leading runtime
hypothesis is code injected by a third-party mobile-browser extension, browser
feature, password manager, translator, debugging bridge, or vendor component. This
runtime attribution is not final until the same device/browser reproducer passes
the isolation procedure below. No Console suppression or business-code workaround
is justified.

REAL-DEVICE ISOLATION / REGRESSION PROCEDURE
1. On the affected phone, record browser name/version, OS version, Ridge Remote URL,
   installed/enabled extensions or content-modifying features, and exact actions.
2. Attach remote DevTools, enable Preserve log, clear Console, reload Ridge Remote,
