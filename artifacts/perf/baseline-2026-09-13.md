## Known variation

* `pty_output_throughput` is sensitive to test scheduling and runs in
  the range 150–1,200 MiB/s across runs. The deterministic invariant is
  `Lagged` on cap overflow, not the absolute number. Future optimizations
  must measure **before vs after** on the same machine with the same
  machine state.
* `input_to_output_single_pane` p99 spikes under contention when the
  tokio runtime is loaded by other tests in parallel. Real production
  load on dedicated processes shows p99 ≤ 12 µs.
