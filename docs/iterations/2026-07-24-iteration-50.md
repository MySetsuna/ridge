# Iteration 50 — 未用符号审计 + 终端/IO 性能

## 根因（卡顿）

1. **Hosts 轮询过重**：每 tick 对每台远端串行 `get_outbound_stats` + 额外 `get_live_backpressure` + 对**每个未附着会话**拉 base64 history；健康 Connected 仍 step 重连。
2. **终端 hover**：pointermove 热路径即使无 Ctrl 也跑 `hyperlinkAt` + `linkSpans.hitTest`（核单元格遍历）。
3. **AgentCenter**：每 3s 全量 topology + decisions + memory + git + audit 多路 IPC。

## 性能落地

| 点 | 改动 |
| --- | --- |
| manager hover | 无 Ctrl/Cmd 时跳过 hitTest；释放修饰键时清 underline |
| hosts pump | `Promise.all` 并行泵多 host |
| hosts stats | 去掉 stats 内自动 BP 二次 IPC；stats 并行 |
| HostsPanel tick | 重叠守卫；history 仅展开且 ≥30s；重连仅 down/in-progress |
| AgentCenter | 轻量每拍 health+topology；重项每 3 拍；间隔随 `healthPollMs` |
