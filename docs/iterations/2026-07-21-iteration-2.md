生成时间：2026-07-21 12:36:11 +08:00  
主题：跨入口 Remote 能力合同门禁

## 本轮完成

1. 建立 Controller-facing 最小能力合同：`pane/invoke/fs/git/search/workspace/theme` 分别声明共享 Controller 真正依赖的 RPC；安全准入仍以 Rust `REMOTE_ALLOWLIST` 为唯一权威，不复制全量命令清单。
2. 新增跨入口合同测试，自动核对：
   - LAN desktop、Cloud desktop 与 Controller 的 capability 名称一致；
   - desktop advertised capability 的必需 RPC 同时存在于安全 allowlist 和 desktop/core handler；
   - rdg advertised capability 的必需 RPC 必须出现在 `route_method`；
   - `get_workspace_snapshot`、`git_diff_file` 保持放行，`get_remote_info/get_remote_totp` 保持排除；
   - Files/Git/Search UI 必须消费协商能力并在主壳与侧栏条件渲染。
3. 先红后绿：新增测试在修复前稳定失败，首个缺口为 rdg 宣告 `fs`，但未路由 Controller 实际调用的 `get_file_tree`；同类缺口还包括 `read_file/text_search`。
4. 修复 rdg 路由：把现有、已 allowlist 的 `get_file_tree/read_file/text_search` 交给 `ridge-core::dispatch`，不新增 RPC、不扩大权限面；不支持方法继续返回 JSON-RPC `-32601 METHOD_NOT_FOUND`。
5. 修复 Controller UI：
   - `RemoteLink` 暴露 capability 查询与变更订阅；Cloud 实现复用 D9 `RpcClient.onNegotiated`，LAN desktop 保持完整能力兼容。
   - MainApp、RemoteSidebar 对 Files/Git/Search 条件渲染；能力在重连协商后下降时，已打开的不支持面板/文件 viewer 会被关闭。
   - 缺 `workspace` 时隐藏新建/关闭 workspace、pane 操作；缺 `theme` 时隐藏主题切换，避免先展示再等待 RPC 报错。
