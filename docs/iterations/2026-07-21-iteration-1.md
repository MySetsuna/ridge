## 本轮完成

1. 逐项审计 NotebookLM note《远程终端迭代规划与质量修复指南》与当前 `main`：
   - 移动复制/选择：已有 copy pill touch 隔离、只读复制与不发送 `^C` 的实现；最近集中修复提交为 `f5010bc`（2026-07-04）。
   - Scrollback/clear：已有 shell `ED 2` 与 API clear 的 scrollback parity；提交 `92b490e`（2026-07-16），并有 Rust 回归测试。
   - 移动白屏/承载力：键盘偏移已改为 transform-independent，终端缓存与本地渲染均有硬上限。
   - Git Diff：`git_diff_file` 已在 core dispatch、Rust allowlist 与 Cloud TS allowlist 中；提交 `e5b1f66`（2026-07-11）。
   - TUI 点击：触屏已把 mouse press/motion/release 转为 TUI mouse reporting；相关实现自 2026-06-14 起存在。
   - 全局滚动条：`overlayScroll`、`rg-os-theme` 与原生 `.rg-scroll` fallback 已存在并有单测。
2. 首次 checker 发现真正失败：Cloud TS allowlist 测试期望 93 项，实际 96 项。
3. 深入比对发现实际漂移：
   - Rust canonical `REMOTE_ALLOWLIST` 有 97 项；TS mirror 缺 `get_workspace_snapshot`，会使 Cloud controller 调用该只读聚合快照时收到 `method not permitted remotely`。
   - Rust canonical `MUTATING_METHODS` 有 33 项；TS mirror 少 11 个 workspace/pane 写操作。该集合当前用于风险分类，不是远程访问 gate，但镜像声明与事实不符。
4. 修复：
   - Cloud TS allowlist 增加 `get_workspace_snapshot`。
   - TS mutating mirror 补齐 11 个 workspace/pane 写操作。
   - 将脆弱的固定数量断言改为直接读取 `packages/ridge-core/src/capability.rs`，对两个数组做逐项、顺序一致校验。
