针对您提出的零散需求与 Bug，我结合现有来源中的**愿景约束 [1, 2]**、**现状证据 [3, 4]** 以及**优先级组合 [5]** 进行了整理与分析。

建议将这些项按功能属性归类，并纳入下个迭代的 **P1（产品主线与工程护栏）** 中。以下是详细分析：

### 一、 远程终端质量与一致性（对应 ID: R1, A2）

这些问题直接关系到 Remote 作为“随处接入控制平面”的可靠性 [1, 6]。

1.  **移动端复制粘贴修复与交互冲突**
    *   **分析**：当前 `TerminalManager` 统一处理输入与选择 [3]，但在移动端浏览器下，点击“复制”触发了输入事件，说明 UI 层的 `selection` 拦截与键盘/IME 触发逻辑在触屏环境下存在分叉 [7]。
    *   **纳入理由**：属于 **R1（弱网与恢复）** 质量范畴，修复交互缺陷是“可控”愿景的基础 [1]。
2.  **Scrollback 加载衔接与 Clear 一致化**
    *   **分析**：现状证据显示 Remote 历史采用“首屏小预算+滚顶懒加载” [4]。`clear` 命令目前可能仅清理了当前的 `grid` 而未同步清理 `ridge-term` 中的 `scrollback` 缓冲区 [2, 3]。
    *   **验收信号**：执行 `clear` 后，向上滚动不应出现历史残余；懒加载衔接处无闪烁或重复帧 [8, 9]。
3.  **单终端承载力优化（防白屏/崩溃）**
    *   **分析**：移动端 Canvas2D 渲染受内存上限限制 [7]。当 `scrollback` 过长或 TUI 刷新频率过高时，容易导致画布内存溢出。
    *   **减法方案**：**不做**全量 GPU 表面扩张（E1），而是对移动端 `scrollback` 设置硬上限，超过阈值时丢弃最旧数据以保护渲染进程 [8, 10]。

### 二、 远程能力矩阵对齐（对应 ID: A2, P1）

1.  **Git Diff 查看器不可用与 "Method not permitted" 错误**
    *   **分析**：这是一个典型的 **A2（跨入口能力矩阵）** 缺口 [8]。`git_diff_file` 可能已在 `ridge-core` 中实现，但由于其未被列入 Remote 的 `allowlist` 或 `CloudHostBridge` 权限门控中，导致远端调用被拒绝 [4]。
    *   **代码证据**：需复核 `cloudHostBridge.ts` 及其权限校验逻辑 [11]。
    *   **纳入理由**：Git 查看器是“可见”愿景的核心组件，用于处理 HITL 审批前的改动复核 [6, 10]。

### 三、 桌面端 UI 规范与 TUI 增强（对应 ID: A1, G1）

1.  **统一全局滚动条样式**
    *   **分析**：这属于 **A1（共享内核减法审计）** 的副作用修复 [12]。随着组件迁入 `ridge-core`，不同宿主环境（Tauri vs Web）的 CSS 变量未完全同步。
    *   **验收信号**：保存工作区列表与终端容器使用相同的 CSS 变量定义的滚动条。
2.  **TUI 程序可点击项支持**
    *   **分析**：`ridge-term` 负责 parser 和 grid 语义 [2, 3]。支持可点击项（如终端内的链接、Agent 状态按钮）需要扩展 PTY 序列解析以支持鼠标报告（Mouse Reporting）和特定转义序列。
    *   **愿景关联**：这能直接增强“可见”性，让用户在 10 秒内切到对应 Pane 或处理审批 [9]。

### 下个迭代规划建议

按照 **GAP_PORTFOLIO 建议的近期组合 [5]**，我建议将上述任务如下分配：

*   **P1 产品主线**：结合 **Remote Agent 控制台 MVP**，修复 **Git Diff 查看器**。
    *   *用户价值*：手机端能直接看到 Agent 改了什么并审批 [6]。
*   **P1 工程护栏**：修复 **移动端复制/渲染白屏** 与 **Scrollback 加载**。
    *   *风险降低*：避免在关键接管时刻因 UI 崩溃导致无法控制 [1]。
*   **P2 连续性补全**：统一桌面端**滚动条**与 **TUI 点击支持**。

**不做范围预警 [13]**：
*   在修复移动端白屏前，**不启动** WebGPU shared surface 的扩张（E1）[5]。
*   在 `clear` 一致性达成前，**不增加** 复杂的 Scrollback 搜索或持久化 RAG 任务 [10]。

**验收信号**：
*   [ ] 手机端点击“复制”不弹出软键盘且剪贴板获得内容 [9]。
*   [ ] `git_diff_file` 在 Remote 模式下成功返回 diff 结构而非 403/MethodNotFound [4]。
*   [ ] 大规模 Scrollback 滚动过程中，移动端内存占用保持稳定 [8]。
