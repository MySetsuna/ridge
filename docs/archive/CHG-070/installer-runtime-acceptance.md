# Installer Runtime exclusion receipt

The approved NSIS hook runs a preflight before the maintenance page can call an older uninstaller. Installation and uninstallation then reserve both existing Kernel boot and instance locks until their post hook. A live or unverifiable registry owner visibly rejects the operation; the installer never stops Runtime or its user processes. Tauri's existing desktop close check remains responsible for closing the old desktop before replacement.

The helper verifies its exact OS-attested installer ancestor, atomically publishes readiness, acknowledges release after dropping locks, and releases automatically when that exact process exits. It neither opens business stores nor clears existing ownership records. The sidecar builder stages the same version-verified Runtime for the helper, independent of target architecture. The unused `NSIS_HOOK_INIT` macro is removed.
